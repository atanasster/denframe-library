# Code of conduct

Treat contributors and users with respect. Give specific, constructive feedback about
work. Harassment, threats, discriminatory abuse, doxxing and unwanted sexual content
are not welcome. Do not publish anyone's private information or household data.

Maintainers may edit or remove inappropriate contributions, close discussions or block
repeat offenders. They will consider context and explain moderation decisions where
possible without exposing private reports. These expectations also apply to maintainers.
Use GitHub's Report content controls for abuse or contact the repository maintainer
through their public GitHub profile. Security vulnerabilities use the private channel
in SECURITY.md. Do not put sensitive personal evidence in public issue comments.
